검증 기준과 운영 원칙

믿을 수 있는 기록이 되기 위한 규칙입니다. 제보자와 대상 모두에게 동일하게 적용됩니다.

1. 검증 절차

단계처리공개 범위
접수 대기 제보·증거 저장. 증거 1건 이상인지 자동 확인. 접수번호(링크)를 가진 사람만
검증 진행중 담당자가 출처·시점·내용 일관성 확인. 필요 시 보완 요청. 공개 (상태 배지 표시)
검증 완료 핵심 주장이 증거로 확인됨. 공개
부분 검증 일부 주장만 증거 확인, 나머지는 확인 불가. 공개 (구간 구분 표시)
반려 증거 불충분·조작 의심·기준 위반. 비공개

제보가 공개되면 대상은 언제든 공식 반론을 등록할 수 있으며, 반론이 승인되면 제보 화면에 반론 등록 상태로 함께 표시됩니다.

2. 증거 기준

모든 제보는 증거 1건 이상을 제출해야 합니다. 다음 기준으로 신뢰도를 판단합니다.

증거인정 요건주의할 점
스크린샷URL·날짜·계정 정보가 보이는 전체 화면편집본은 반려. 부분 캡처는 부분 검증
영수증·거래내역상호, 금액, 일시, 결제 수단이 식별 가능카드번호·계좌번호는 마스킹
계약서·서류당사자·일자·약정 조항 확인 가능주민번호 등 개인정보 마스킹
녹취·통화기록일시, 상대방 식별 가능. 파일 또는 상세 기록불법 녹취 등 위법 수집물은 반려
문자·메신저대화 상대·시간 표시 포함타인 대화 무단 공개 주의
외부 링크직접 접근 가능한 공개 게시물삭제 시 근거 상실 → 재검토

반려 사유

  • 증거 없음, 또는 증거가 주장과 무관한 경우
  • 편집·조작이 의심되는 이미지 (여러 장 불일 포함)
  • 실명·욕설·비방 중심이며 사실 관계가 빈약한 경우
  • 개인정보(주민등록번호, 주소, 전화번호 등)를 마스킹하지 않은 경우
  • 같은 사건의 중복 제보가 이미 검증 완료된 경우

3. 반론권 정책

  • 제보의 대상(기업·매장)은 언제든 공식 반론을 등록할 수 있습니다.
  • 반론에는 확인 가능한 근거(허가번호, 결제 기록, 회신 기록 등)를 함께 제출해야 합니다.
  • 반론은 관리자 검토 후 공개되며, 게시된 제보 하단에 동일한 비중으로 표시됩니다.
  • 반론이 승인되면 제보 상태는 반론 등록으로 전환됩니다.
  • 증거가 제출된 정정 요청은 사실 확인 후 제보 내용을 수정하거나 상태를 조정합니다.

4. 개인정보 보호

  • 제출 전 이름·전화번호·주소·주민등록번호는 반드시 마스킹하세요.
  • 기본 설정은 익명 제보이며, 표시명을 지정하지 않는 한 작성자 정보는 공개되지 않습니다.
  • 타인의 대화·서류를 공개할 때는 당사자 동의가 필요합니다.
  • 증거 파일은 공개 스토리지에 저장되므로, 업로드 전 마스킹을 다시 확인하세요.
  • 개인정보 침해가 확인되면 신고 접수 즉시 해당 증거는 비공개 처리됩니다.

5. 신고 · 정정 요청

다음의 경우 관리자에게 정정·삭제를 요청할 수 있습니다.

  • 허위 또는 조작된 증거가 포함된 경우
  • 개인정보가 포함된 경우
  • 실제와 다른 사실이 확인된 경우 (반론 + 근거 제출)
  • 저작권·영업비밀 침해가 인정되는 경우
요청 방법 관리자 페이지(admin)의 문의 채널 또는 제보 상세의 "신고·정정 요청"을 통해 해당 제보의 URL과 사유를 보내 주세요. 확인 후 결과를 회신합니다.

6. 면책 조항

  • 본 사이트의 제보는 제3자가 제출한 주장이며, 플랫폼이 이를 보증하지 않습니다.
  • 검증 완료 표시는 증거의 존재와 정합성을 확인한 것이지, 법적 판단이나 분쟁의 결론이 아닙니다.
  • 제보 내용에 따른 법적 책임은 해당 제보자에게 있습니다.
  • 실제 분쟁 해결은 소비자상담센터(1372), 경찰, 법원 등 공식 기관을 이용해 주세요.
  • 운영자는 위법·명예훼손·개인정보 침해 게시물을 임의로 비공개 처리할 수 있습니다.
